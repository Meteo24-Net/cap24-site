# Platform icons for /social

The social page looks for these files and shows each one in its platform button:

- `facebook.svg`
- `instagram.svg` (used for Instagram and Instagram Stories)
- `linkedin.svg`
- `tiktok.svg`

Until a file is here, its button shows the platform name only.

Rules (spec GMF-WEB-SOC-001, section 8.10):

- Use each platform's own single-colour icon, downloaded from its brand resource page (Meta for Facebook and Instagram, LinkedIn, TikTok).
- Do not redraw, recolour beyond what the guidelines allow, combine with CAP24 marks, or animate.
- Check each brand's rules (clear space, minimum size, referential use) before adding the file, and record the check in the spec.
- The page states: "Formats sized for these platforms. Not affiliated with or endorsed by them."
